# ha-scanservjs-addon
home assistant addon that run scanservjs, the webservice to use scanner. 

this addon is compatible with home assistant green (x64) and allow you to transform your HA server into a scanner host.


- plug the printer
- install/start the application
- go to the webui and enjoy

work well with paperless to send directly the scanned files into the sink
think smart: add a smart button to automagicaly scan and archive your scanned files
